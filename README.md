# Ayla Grid Bot v0.7 (PAPER ONLY)

## Нове
- Інтерактивний графік на TradingView Lightweight Charts v4 (CDN): zoom колесом, pan мишкою, час, OHLC, BUY/SELL рівні, маркери Paper-угод, fit/realtime. Якщо CDN недоступний — базовий Canvas-графік.
- До 500 свічок у графіку, оновлення кожні 30 с.
- `.env` правильно читає коментарі після значень: `BYBIT_ENV=testnet # comment`.
- Зберігається стан Start/Pause у SQLite між перезапусками. Після помилки котирувань бот переходить у PAUSE і не відновлює торгівлю автоматично.
- Перевірка свіжості котирувань перед Start, окремий `quote_age_seconds` у статусі.
- Існуюча база `ayla_v04.db` не видаляється; міграція додає тільки ключ налаштувань.

## Оновлення Raspberry Pi

1. Зупини службу: `sudo systemctl stop ayla-grid`.
2. У `~/ayla_grid_bot` зроби копії `main.py`, `index.html`, `ayla_v04.db`.
3. Перенеси **main.py**, **index.html** та за потреби **requirements.txt** з архіву в `~/ayla_grid_bot`.
4. **Не замінюй** `.env`, `ayla_v04.db`, Telegram-налаштування.
5. Перевір `.env`: `BYBIT_ENV=mainnet` рекомендовано для Paper на реальних котируваннях; `testnet` — тестові котирування.
6. Запусти: `.venv/bin/python -m py_compile main.py && sudo systemctl start ayla-grid`.
7. Перевір: `sudo systemctl status ayla-grid --no-pager` та `curl -fsS http://127.0.0.1:8090/api/health`.
8. Відкрий вебпанель, зроби Ctrl+F5.

## Безпека

- **Немає реальних ордерів**. API-ключі не використовуються для торгівлі.
- Вебпанель без авторизації. Не відкривай порт у публічний інтернет; краще `HOST=127.0.0.1` і SSH-тунель.
- Інтерактивна бібліотека вантажиться через CDN; якщо CDN недоступний, показується базовий графік. Для повністю автономного режиму потрібен локальний JS-файл.
- Backtest приблизний, без прослизання, а Paper-середовище не гарантує прибутку.
- `BYBIT_ENV` не змінює вже записану історію Paper: не змішуй результати різних середовищ.
